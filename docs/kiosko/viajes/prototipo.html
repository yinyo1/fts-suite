Corregir SO (modal de hoy + empresa)

Cómo propone el sistema el tipo de día Con la zona de la primera checada (entrada) y la de la última (salida): MX → MX = México · USA → USA = Proyecto USA MX → USA = Viaje a USA · USA → MX = Viaje a México Si falta la zona de un evento (checada vieja o fuera de zona) se usa el plan; si tampoco hay plan, queda sin tipo y no se puede confirmar. Felipe lo cambia con el selector; el cambio queda en el chatter con el valor propuesto y el elegido. Candado nuevo: un día de viaje (modalidad viaje en el plan, o tipo Viaje a USA / Viaje a México) no se confirma sin SO o centro de costos.
